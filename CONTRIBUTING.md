# Contributing

Thanks for helping keep this list accurate. Free tiers change constantly, so every contribution with a verified source helps.

## Acceptance criteria

A service should have:

1. A genuinely useful free tier
2. Publicly documented pricing and limits
3. A currently active free plan
4. Something distinct from existing entries

Services that are free for only a few days, without meaningful credits, will not be accepted.

## Submission template

Please include all of the following in your PR or issue:

```text
Service:
Category:
URL:
Free-tier limits:
Card required (yes/no/varies):
Type (free forever / credits / trial):
Commercial use allowed (yes/no/unknown + link to terms):
Sleep or expiry behavior:
Last verified date (YYYY-MM-DD + link to pricing page):
Notes / where you hit the wall:
```

## Verified column

* Use `⏳` if you have not checked the pricing page recently.
* Use a date (`2026-10-08`) if you checked the pricing page on that day.
* Treat all limits as approximate and link to the official pricing page.

## Edits to existing rows

If a free tier changed, please link to the current pricing page and update the limits, card requirement, and verified date in the same PR.
